# 🚀 Real-Time Chat Application

A full-stack real-time chat application built using the **MERN Stack** with **Socket.IO** for instant messaging and a modern responsive UI.

---

## Live Demo

[Visit Application] : https://realtimechatapp-qn43.onrender.com/
---

## 🌟 Features

- 🔐 JWT Authentication & Authorization
- 💬 Real-Time Messaging with Socket.IO
- 🟢 Online/Offline User Status
- 📡 RESTful API Integration
- ⚡ Fast Frontend using Vite
- 🎨 Responsive UI with Tailwind CSS
- 🔒 Protected Routes
- 📦 MongoDB Database Integration
- 🛠️ Clean & Scalable Backend Architecture

---

# 🛠️ Tech Stack

## Frontend
- ⚛️ React.js
- ⚡ Vite
- 🎨 Tailwind CSS
- 📡 Axios
- 🔄 Socket.IO Client

## Backend
- 🟢 Node.js
- 🚂 Express.js
- 🍃 MongoDB
- 🔐 JWT Authentication
- 🔄 Socket.IO
- 🛡️ Express Middleware

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/your-repository-name.git
```

---

## 2️⃣ Install Backend Dependencies

```bash
cd backend
npm install
```

---

## 3️⃣ Install Frontend Dependencies

```bash
cd frontend
npm install
```

---

# 🔑 Environment Variables

Create a `.env` file inside the `backend` folder and add:

```env
PORT=8000
MONGODB_URL="your_mongoDB_URL"
JWT_SECRET="your_jwt_secret"
NODE_ENVIRONMENT="development"
CLOUDINARY_CLOUD_NAME='your_cloudinary_cloud_name'
CLOUDINARY_API_KEY='your_cloudinary_api_key'
CLOUDINARY_API_SECRET='your_cloudinary_api_secret'

```

---

# ▶️ Run the Application

## Start Backend Server

```bash
cd backend
npm run dev
```

---

## Start Frontend

```bash
cd frontend
npm run dev
```
